This page belongs to a controlled test site built to validate a website crawler. Every page here is written to be technically clean unless a fault was planted on purpose, so that anything a detector reports can be compared against a known list. The site is served by a small local server that answers with real status codes and real redirects, which is something a static hosting service cannot do. Each planted fault is described in a separate answer key, together with the page it lives on and the pages that link to it, and a scoring script compares every crawl with that key. A detector passes only when it finds every planted fault and reports nothing else, because a tool that cries wolf is as unhelpful as one that misses problems. Control pages carry no faults at all and must stay quiet in every run. The body text on each page is deliberately long, written in plain sentences, and checked by hand, so that rules about short pages, repeated words or leftover template text have a fair and realistic page to read. When a new detector is added, a new page with exactly one new fault is added beside it, the answer key grows by one entry, and the continuous integration job raises the number of faults it expects to find before any change can be merged. Nothing on this site is real: the offices, services and people named here exist only to give the detectors something believable to read, and no page collects any data from the people or tools that visit it. Anyone can run the whole site on a laptop in a few seconds, which keeps the feedback loop short for everyone working on the crawler.
